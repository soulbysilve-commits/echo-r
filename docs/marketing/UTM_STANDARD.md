# UTM Standard

Format: `utm_source=<channel>&utm_medium=<medium>&utm_campaign=<campaign>&utm_content=<content>`

## utm_source values
`x`, `discord`, `youtube`, `producthunt`, `reddit`, `hackernews`, `zenn`, `qiita`, `note`, `site_news`, `site_blog`

## utm_medium values
`organic`, `social`, `community`, `video`, `email` (email not yet in use), `referral`

## utm_campaign naming
`<product>_<theme>_<yyyymm>`, e.g. `echo_agent_verifier_demo_202609`, `noemora_first_seven_202609`.

## utm_content naming
Short slug for the specific creative/angle, matching the FACT id's theme where possible, e.g. `resume_demo`, `verifier_reject_demo`, `continuity_gate_demo`.

## Rules
- Every externally-published link must carry UTM parameters generated by `tools/marketing/lib/utm.mjs` (to be added when the first live channel is connected) — never hand-typed, to avoid typos that break attribution.
- UTM parameters are never applied to internal links (nav, footer, cross-page links) — only to links shared externally (posts, videos, PR profiles).
- `utm_campaign` must match an entry in the publication ledger's `campaign` column so performance can be joined back to the marketing_memory table.
